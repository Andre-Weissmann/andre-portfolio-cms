The Question

What drives Airbnb pricing in Seattle, and how much money are hosts leaving on the table by ignoring the data?

Most Seattle Airbnb hosts set nightly rates by gut feel: they check a few nearby listings, pick a number that feels competitive, and rarely revisit it. That approach ignores three variables that actually move revenue: where a listing sits, how many bedrooms it has, and when it's booked.

This project pulls a full year of Seattle listing data into Tableau to quantify the gap between gut-feel pricing and data-driven pricing, and to show exactly which levers close that gap.

The Process

How the dashboard was built in Tableau, from raw tables to cross-filtered sheets.

  1. Data connection and relationship setup
    Listings and calendar tables joined on listing ID, giving each listing its full year of price and availability history in one model.
  2. Calculated field for annual revenue
    Annual revenue derived as the sum of available price multiplied by booked nights, rolled up per listing.
  3. Geographic dimension: zip code as categorical
    Zip code set as a categorical dimension and mapped to Seattle coordinates to enable the choropleth revenue map.
  4. Built 5 sheets
    Price by zip code bar chart, revenue map, seasonal line chart, price by bedroom count bar chart, and a listing count table by zip code.
  5. Dashboard assembly with cross-filter actions
    All five sheets combined into one dashboard using layout containers, with cross-filter actions wired to the zip code dimension so clicking any zip updates every sheet.
Example calculated fields
Annual Revenue = SUM([Price]) * [Booked Nights]
Avg Price by Zip = AVG([Price])

The Recommendation

What the data reveals

Three variables explain the majority of nightly price variation across Seattle Airbnb listings: zip code, bedroom count, and booking week. Zip code 98134 had the highest average price in the dataset, yet hosted listings priced significantly below comparable zip codes — a gap of roughly $110 per night relative to nearby listings with similar bedroom counts.

  • 1 Zip code explains a 3x spread in nightly rates across Seattle — location is the strongest pricing signal in the dataset.
  • 2 Bedroom count compounds: 4-bedroom properties earn 3.3x more per night than 1-bedrooms. The relationship is not linear — each additional bedroom adds a disproportionate premium.
  • 3 Summer weekly revenue peaks 60% above January. The four highest-revenue weeks of 2016 fell in March, May, June, and December — spring and holiday seasons drove the clearest demand spikes.

The seasonal pattern is consistent and predictable: spring and holiday weeks outperform the rest of the year by a measurable margin, making timing one of the clearest levers available for maximizing annual revenue.

The dashboard makes all three pricing levers interactive — zip code, bedroom count, and week — so any combination can be explored against the full 2016 Seattle dataset.

The Dashboard

What each of the 5 sheets does and why

The finished Tableau dashboard combines five sheets into one interactive view. Clicking any zip code on the map updates every other sheet simultaneously.

Sheet 1
Advertised Average Home Price by Zip Code

Bar chart ranked by average nightly price. Immediately shows which zip codes command premium pricing and which are priced below comparable areas. Zip code filter applied here updates all other sheets.

Sheet 2
Average Home Price by Zip Code (World Map / Choropleth)

Geographic view of price distribution across Seattle. Longitude and latitude columns from the Listings table drove this. Color density encodes price tier, making the $110/night gap in zip code 98134 visible at a glance on the map.

Sheet 3
Yearly Revenue for 2016 (Week by Week)

Line chart showing weekly revenue across the full calendar year. Color density encodes revenue magnitude. This is where the four peak-revenue weeks surfaced: March 27th ($1.9M), May 29th ($2.0M), June 19th ($2.1M), and December 25th ($2.1M).

Sheet 4
Average Home Price by Bedroom Count

Horizontal bar chart showing how nightly price scales with bedroom count. The relationship is not linear: 6-bedroom properties earn disproportionately more per bedroom than 2-bedroom properties, which matters for hosts considering property upgrades.

Sheet 5
Number of Homes by Bedroom Count

Companion to Sheet 4. Shows supply volume per bedroom tier. The peak at 1-bedroom (1,811 listings) vs. the scarcity of 5+ bedroom listings explains part of the per-bedroom pricing premium at higher counts.

Key takeaway

Joining three tables (Listings, Calendar, Reviews) in Tableau requires understanding which columns connect them before you open the tool. The listing_id pattern that connected all three worksheets was the first thing identified in the raw data. Getting the join wrong at that stage would have corrupted every downstream calculation. The data cleaning and relationship mapping happened before Tableau was even opened.
