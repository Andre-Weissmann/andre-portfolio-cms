Proof rail · what makes this a DataGlow dashboard

  • VERDICT on every tile (GREEN / RED / GRAY / AMBER), not a naked chart.
  • Dual-engine stamps so a second runtime can disagree and pull a claim down.
  • Cleaning rule in the chrome (NR never as 0) instead of buried footnotes.
  • Different grain honesty: Quality PUF and IDR are separate files. No fake join.
  • Human confirm before any number is portfolio-ready. Propose → prove → confirm.
  • Product path: Ingest → Purpose → Validate → Scout → Prove → Narrate → Export ship pack.
